## ✨ What is this?

**EWU Smart Routine Generator** is a lightweight web tool that turns your **East West University Advising Slip (Excel)** into a clean, printable weekly class routine — automatically.

No more manually copying course, section, time, and room info into a table. Upload the slip, and your routine builds itself.

<div align="center">

```
📄  Advising Slip (.xlsx)  ──▶  ⚙️  Smart Parser  ──▶  📅  Visual Weekly Routine
```

## 🎯 Features

| | Feature | Description |
|---|---------|--------------|
| 📤 | **Excel Upload** | Upload your official EWU Advising Slip directly — no manual data entry |
| ⚡ | **Auto-Generate** | Parses course, section, time, and room info into a full weekly grid |
| ✏️ | **Edit / Add Slots** | Tweak generated slots or add new ones manually |

## 🚀 How to Use

```
1️⃣  Open the app → ewu-smart-routine-generator.vercel.app
2️⃣  Click "Upload Advising Slip" and select your .xlsx file
3️⃣  Hit "GENERATE" and watch your routine build itself
4️⃣  Use "EDIT / ADD COURSES" to fine-tune any slot
5️⃣  Click "DOWNLOAD PNG" or "PRINT" to save/share it
```

### Run locally

```bash
git clone https://github.com/Zahid074/EWU_Smart_Routine_Generator.git
cd EWU_Smart_Routine_Generator
# then just open index.html in your browser
```
